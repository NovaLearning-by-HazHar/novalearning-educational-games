# 🌍 NovaLearning Games

**Educational games for Grade R (ages 5-6) — Ubuntu philosophy meets South African culture**

*"I am because we are"*

## 🎮 Games

### Letter Recognition (A-F)
The first game in the NovaLearning suite. Each letter is paired with a South African animal and an Ubuntu value:

| Letter | Animal | Ubuntu Value |
|--------|--------|-------------|
| A | Aardvark (iSambane) | Appreciation |
| B | Buffalo (iNyathi) | Bravery |
| C | Chameleon (uNwabu) | Compassion |
| D | Dragonfly (uZiyane) | Dignity |
| E | Elephant (iNdlovu) | Empathy |
| F | Flamingo (iNtshe ePhinki) | Friendship |

### Gameplay Flow
1. **Introduction** — Meet the letter, its animal, and Ubuntu value
2. **Tracing** — Trace the letter shape with your finger
3. **Matching** — Find the correct letter among options
4. **Results** — Earn stars and collect Ubuntu values

### Three Difficulty Levels
- 🌱 **Guided** — Full support with hints and audio prompts
- 🌿 **Assisted** — Fewer hints, encouragement on mistakes
- 🌳 **Independent** — Minimal support, demonstrates mastery

## 🛠️ Tech Stack

- **Phaser 3.88** — 2D game engine
- **Vite** — Build tool
- **Zustand** — State management
- **Howler.js** — Audio
- **PWA** — Offline-capable, installable

## 📱 Target Device

Samsung Galaxy A03 (low-end Android):
- 720x1600 display
- 30fps target
- <3s load time
- <50MB total assets
- Full offline support
