# /ubuntu — Ubuntu Philosophy Alignment Check

Audit game mechanics and content for Ubuntu philosophy ("I am because we are") alignment.

## Instructions

Scan the current codebase and game design for Ubuntu philosophy compliance. Every NovaLearning game must reinforce cooperative, community-centered values.

### Check these principles:

1. **Cooperative > Competitive**: Flag any scoring systems, leaderboards, or win/lose mechanics that pit players against each other. Acceptable: group progress bars, shared achievements, team milestones.

2. **Helping Mechanics**: Verify game mechanics involve helping characters, sharing resources, or building community. Flag: defeating enemies, eliminating opponents, hoarding resources.

3. **Community Celebration**: Check victory/success screens. Should celebrate group achievement ("We did it together!") not individual glory ("You're the best!"). Flag individual-focused reward language.

4. **Inclusive Language**: Scan all text content, UI labels, and dialog for inclusive, community-oriented language. Flag exclusionary or individualistic phrasing.

5. **Cultural Authenticity**: Check character names, environments, and stories for South African cultural representation. Flag generic/Western-default content that should be localized.

6. **Sharing Mechanics**: Look for resource-sharing, turn-taking, or cooperative puzzle-solving mechanics. These are encouraged. Flag single-player-only mechanics with no social element.

### Output format:

```
## 🌍 Ubuntu Philosophy Report

### ✅ Aligned
- [mechanics/content that embody Ubuntu values]

### ⚠️ Needs Adjustment
- [items that could be more Ubuntu-aligned, with suggestions]

### 🚨 Misaligned
- [items that contradict Ubuntu values, with specific fixes]

### 💡 Enhancement Opportunities
- [ways to deepen Ubuntu integration]

### Ubuntu Score: [1-10] / 10
```

If no game content found, provide Ubuntu design guidelines for the next game being built.
