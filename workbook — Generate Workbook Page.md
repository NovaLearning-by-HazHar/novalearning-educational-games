# /workbook — Generate Workbook Page

Generate a print-ready educational workbook page for NovaLearning Grade R students (ages 4-6).

## Instructions

Create a workbook activity page following these requirements:

### Curriculum Alignment
- Target: South African CAPS curriculum, Grade R
- Age: 4-6 years old
- Language: English (MVP)
- Must include clear learning objective mapped to CAPS

### Page Structure
1. **Header**: Activity title, page number, learning area icon
2. **Instructions**: Simple, clear instructions a teacher/parent can read aloud (max 2 sentences)
3. **Activity Area**: The main activity (tracing, matching, counting, coloring, etc.)
4. **QR Code Zone**: Space for QR code that triggers the corresponding 3D web game
5. **Footer**: NovaLearning branding, "Scan to Play!" prompt

### Design Requirements
- A4 portrait orientation
- Black and white (cost-effective printing for SA schools)
- Large, clear illustrations suitable for young children
- Thick lines for tracing activities (min 3pt stroke)
- South African cultural elements (animals, landmarks, foods, clothing)
- Ubuntu-themed cooperative scenarios where possible

### Content Categories (use $ARGUMENTS or ask):
- **counting**: Numbers 1-10 with SA animals
- **letters**: Letter recognition and tracing
- **shapes**: Shape identification with real-world SA objects
- **patterns**: Pattern completion activities
- **colors**: Color matching (for color-printed versions)
- **social**: Ubuntu-themed sharing/helping scenarios

### Output
Generate the page as HTML that can be converted to PDF, or provide specifications for the workbook-page-generator skill. Include:
- Complete activity content
- Illustration descriptions (for artist or AI generation)
- QR code placement coordinates
- Corresponding game mechanic description

### Quality Checklist
- [ ] Age-appropriate difficulty (4-6 year olds)
- [ ] CAPS curriculum aligned
- [ ] Culturally authentic (SA context)
- [ ] Ubuntu values present
- [ ] Clear teacher/parent instructions
- [ ] QR code space included
- [ ] Print-friendly (B&W compatible)
